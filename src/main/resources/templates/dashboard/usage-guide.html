Fare Grid & Pricing Management

Selecting Tenant Context

The Point-to-Point (O-D) Rate Grid allows operators to review and update route-specific fares across product classes. Fares are arranged in a 2D matrix where rows represent outbound destination terminals and columns represent ticket products.

1. Select Tenant Environment

Choose an active Point-to-Point tenant (e.g., NY Waterway). The workspace will adapt its secondary filters specifically for O-D terminal routing.

2. Choose Origin Terminal

Select the departure terminal (e.g., EDGEWTR, PORTIMP, or MIDTOWN). The grid will load outbound destinations served from that location.

Editing Point-to-Point (O-D) Fares Inline

Editing Actions
  • Open Editor: Click directly on any active price cell, or navigate to it using keyboard focus and press Enter or Space.
  • Spreadsheet-Style Overwrite: When first opened, the existing number is fully selected. Typing any digit immediately replaces the old rate without needing to backspace first.
  • Precision Caret Placement: Click inside the active input box to place the cursor at a specific character position and switch to standard text insertion.
  • Confirm Edit: Press Enter or click anywhere outside the cell (Blur) to validate and format the new rate.
  • Cancel Edit: Press Esc at any time while typing to discard your change and restore the previous rate.
Sanitization & Auto-Formatting
  • Smart Zero-Padding: Whole dollar values (e.g., 14) normalize to $14.00. Single decimals (e.g., 14.5) normalize to $14.50.
  • Input Masking: Minus signs (-), plus signs (+), scientific notation (e), letters, and symbols are blocked on keystroke.
  • Decimal Limiting: Only one decimal point and a maximum of two decimal places are accepted.
  • Paste Sanitization: Pasting values with currency symbols (e.g., $16.50) automatically strips the $ and validates the amount.

Keyboard Navigation & Rapid Entry

Key / Shortcut Action Description
Tab Commit & Next Cell Validates the current cell and moves the inline editor directly to the next editable rate cell in the matrix.
Shift + Tab Commit & Previous Cell Validates the current cell and moves backward to the preceding editable rate cell.
↑ / ↓ Arrows Step Rate by ±$0.01 Increments or decrements the rate by one cent. Values cannot be stepped below the $0.00 boundary.
Enter Commit Rate Saves and closes the active input, formatting the number into standard currency display.
Esc Cancel Edit Closes the input immediately without applying any unsaved edits.

Cell States & Locked Route Feedback

$13.25 Active Rate

Standard pricing intersection. Fully editable inline with real-time numeric validation.

NOT_SOLD Disabled

The ticket product is not sold for this route. Clicking triggers a warning banner and locks text entry. Product availability rules must be modified first.

N/A Unserved

Unserved terminal-to-destination combination (e.g., Edgewater to Pier 11). Clicking triggers an informational alert; rates cannot be assigned.
